# Демонстрационные материалы проекта «СтатМетод»

- `СтатМетод_презентация.pptx` — презентация на 16 слайдов для предварительной аттестации.
- `СтатМетод_презентация.pdf` — версия презентации для просмотра.
- `СтатМетод_демонстрация.mp4` — сокращённая по размеру видеозапись интерфейса (примерно 3 минуты, 1920×868, без звука).
- `СтатМетод_доклад.docx` — речь по 16 слайдам.
- `СтатМетод_комментарии_к_видео.docx` — отдельный текст комментариев к видео.

Все материалы относятся к локальному учебному прототипу, а не к промышленной системе Росстата.

**Важно:** видеозапись не подтверждает сохранение новой ОСМ: ролик заканчивается на форме добавления. Работа сервера и базы требует отдельной проверки.

Демонстрационные материалы могут содержать служебные наименования/сведения из задания: проверьте право публикации перед размещением в общедоступном репозитории.
