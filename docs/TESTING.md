# Тестовые сценарии

Документ содержит набор сценариев для проверки основных функций
приложения. Каждый сценарий описывает цель, шаги и ожидаемый
результат. Сценарии охватывают ключевые части проекта: загрузку
шаблона, ввод полей, справочник ФПСР, повторяемые группы, формулы,
сохранение, валидацию, Word-выгрузку и ИИ-помощника.

## Подготовка

Перед тестированием:

1. Backend запущен: `uvicorn app.main:app --reload --port 8000`.
2. Frontend запущен: `npm run dev`.
3. Открыт адрес http://localhost:5173.
4. Проект в исходном состоянии: нажать «Сбросить проект» в шапке.
5. Для сценария 9 дополнительно настроен `backend/.env`
   с ключами YandexGPT.

## Сценарий 1. Загрузка шаблона

**Цель:** убедиться, что backend читает JSON-шаблоны и отдаёт их
фронтенду.

**Шаги:**

1. Открыть http://localhost:8000/api/template.
2. Открыть http://localhost:8000/api/template/sections/section_01_general.

**Ожидаемый результат:** приходят JSON-манифест с 7 разделами и
JSON раздела «Общие положения». Статус ответа — 200.

## Сценарий 2. Отображение разделов

**Цель:** проверить навигацию и рендер интерфейса по шаблону.

**Шаги:**

1. Открыть http://localhost:5173.
2. По очереди кликнуть каждый из 7 разделов в левой панели.

**Ожидаемый результат:** для каждого раздела отображается заголовок,
описание и все блоки. Заголовки, абзацы, поля, повторяемые группы,
классификаторы и расчётные блоки отрисованы в правильном порядке.

## Сценарий 3. Заполнение обязательных полей раздела I

**Цель:** проверить ввод текста и статус заполнения.

**Шаги:**

1. Открыть раздел I.
2. Заполнить поля «Название Методологии», «Подпункт пункта 5
   Положения о Росстате», «Что характеризует официальная
   статистическая информация», «Цели использования официальной
   статистической информации».
3. В поле «Позиции ФПСР» добавить позицию `1.2.2.` через модалку.

**Ожидаемый результат:** иконка раздела I в сайдбаре становится
зелёной, тег «Заполнено: 1 / 7» в шапке обновляется.

## Сценарий 4. Справочник ФПСР

**Цель:** проверить поиск и вставку позиций.

**Шаги:**

1. В разделе I нажать карандаш рядом с «позицией ФПСР».
2. Ввести в поиск `1.2`.
3. Выбрать позицию `1.2.6.`.
4. Закрыть модалку.
5. Открыть раздел VII, посмотреть пункт 7.2.

**Ожидаемый результат:** в пункте 1.3 появляется текст «позициями
1.2.2., 1.2.6.». В пункте 7.2 автоматически выводится «согласно
позициям 1.2.2., 1.2.6. ФПСР» в дательном падеже.

## Сценарий 5. Повторяемые группы

**Цель:** проверить добавление и удаление строк.

**Шаги:**

1. Открыть раздел IV.
2. Добавить три показателя.
3. Удалить второй.
4. Переключиться на другой раздел и вернуться в IV.

**Ожидаемый результат:** строки добавляются, удаляются, порядок
сохраняется. Значения не теряются.

## Сценарий 6. Пункт 5.2 с защищённой первой строкой

**Цель:** проверить `lock_first_row` и правило нумерации.

**Шаги:**

1. Открыть раздел V.
2. Убедиться, что первая строка 5.2 без кнопки удаления.
3. Добавить вторую строку.
4. Удалить вторую.

**Ожидаемый результат:** первая строка не удаляется; вторая
добавляется и удаляется; номер 5.2 отображается только у первой.

## Сценарий 7. Формулы и KaTeX

**Цель:** проверить расчётные блоки и предпросмотр формулы.

**Шаги:**

1. В разделе IV задать показатель (например, «Выпуск товаров
   и услуг», код ОКЕИ 384).
2. Открыть раздел VI.
3. Убедиться, что автоматически создан расчётный блок.
4. Ввести обозначение `Oy`, формулу `Oy = O_NK + O_DH`,
   расшифровку в три строки.

**Ожидаемый результат:** формула отображается в предпросмотре
KaTeX с подстрочными индексами. При удалении показателя в разделе IV
блок в VI исчезает.

## Сценарий 8. Сохранение проекта

**Цель:** проверить localStorage.

**Шаги:**

1. Заполнить несколько полей в разных разделах.
2. Обновить страницу (F5).
3. Открыть те же разделы.

**Ожидаемый результат:** все значения сохранены. В DevTools →
Application → Local Storage присутствует ключ
`methodology-project-v1`.

## Сценарий 9. ИИ-помощник

**Цель:** проверить обращение к YandexGPT.

**Шаги:**

1. Открыть любой раздел.
2. В панели «ИИ-помощник» нажать «Объяснить».
3. Дождаться ответа.
4. Ввести в поле произвольный текст, нажать «Улучшить».

**Ожидаемый результат:** в зелёном блоке появляется осмысленный
ответ на русском языке. Для действия «Улучшить» текст перефразирован
в официальном стиле.

## Сценарий 10. Валидация перед выгрузкой

**Цель:** проверить предупреждение о незаполненных полях.

**Шаги:**

1. Оставить часть разделов незаполненными.
2. Нажать «Скачать Word».

**Ожидаемый результат:** появляется модальное окно со списком
незаполненных пунктов и кнопками «Всё равно скачать» и «Вернуться
к заполнению». Длинные формулировки переносятся внутри тега и не
выходят за границы модалки.

## Сценарий 11. Генерация Word

**Цель:** проверить полный цикл выгрузки.

**Шаги:**

1. Заполнить раздел I полностью.
2. В разделе IV добавить два показателя.
3. В разделе VI заполнить первый расчётный блок.
4. В разделе VII включить блок ЕМИСС и указать ссылку.
5. Нажать «Скачать Word».
6. Открыть файл `methodology.docx` в Microsoft Word.

**Ожидаемый результат:**

- присутствует титульный блок «УТВЕРЖДЕНА / приказом Росстата / дата»;
- заголовок методологии с подставленным названием;
- раздел I с заполненными полями и позициями ФПСР;
- раздел IV: строки перечислены с `;` в середине и `.` в конце;
- раздел VI: формула с курсивом и подстрочными индексами,
  номер формулы справа; расшифровка курсивом;
- раздел VII: включённый блок ЕМИСС с указанной ссылкой.

## Сценарий 12. Сброс проекта

**Цель:** проверить очистку данных.

**Шаги:**

1. Заполнить несколько полей.
2. Нажать «Сбросить проект» и подтвердить.
3. Обновить страницу.

**Ожидаемый результат:** все поля пустые, счётчик «Заполнено: 0 / 7»,
все иконки серые. Значения в localStorage удалены.

## Сценарий 13. Адаптивность

**Цель:** проверить поведение интерфейса при разной ширине окна.

**Шаги:**

1. Развернуть окно на весь экран — панель ИИ справа.
2. Сузить окно до 1000 px.
3. Снова развернуть.

**Ожидаемый результат:** при сужении панель ИИ скрывается, появляется
кнопка «ИИ-помощник» в шапке; при развороте панель возвращается.
Заголовок в шапке усечён с многоточием, полный текст доступен
в тултипе.

## Что не покрыто

- Полноценный экспорт в других форматах (PDF, ODT).
- Загрузка ранее сохранённых проектов из файла.
- Многопользовательский режим и серверное хранение проектов.
