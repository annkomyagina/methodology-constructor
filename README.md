# Конструктор официальной статистической методологии

Прототип веб-приложения для подготовки официальной статистической
методологии Росстата в структурированном виде. Пользователь заполняет
разделы методологии через веб-интерфейс, использует справочник ФПСР,
получает помощь от YandexGPT и выгружает готовый документ в формате Word.

## Возможности

- 7 разделов методологии, соответствующих официальному шаблону;
- поддержка типов полей: текст, многострочный текст, выбор, повторяемые
  группы, справочные значения ФПСР, формулы, классификаторы;
- встроенный справочник Федерального плана статистических работ
  (1 939 позиций);
- автоматическая проверка заполнения обязательных полей;
- сохранение проекта в браузере (localStorage);
- ИИ-помощник на базе YandexGPT: объяснить, улучшить, предложить, проверить;
- выгрузка готового документа в Microsoft Word (DOCX).

## Структура проекта

    methodology-constructor/
    ├── backend/          # FastAPI: API, генерация DOCX, YandexGPT

    │   └── requirements.txt

    │   └── src/

    └── README.md

## Требования

- Python 3.10+
- Node.js 18+
- (для ИИ) аккаунт Yandex Cloud с сервисным аккаунтом

## Запуск

### 1. Backend

    cd backend
    python -m venv venv
    venv\Scripts\activate            # Windows
    # source venv/bin/activate        # macOS / Linux
    pip install -r requirements.txt
    uvicorn app.main:app --reload --port 8000

Backend будет доступен на http://localhost:8000  
Автодокументация API: http://localhost:8000/docs

### 2. Frontend

    cd frontend
    npm install
    npm run dev

Frontend будет доступен на http://localhost:5173

### 3. Настройка YandexGPT (опционально)

Создайте файл `backend/.env`:

    YANDEX_FOLDER_ID=ваш_folder_id
    YANDEX_API_KEY=ваш_api_key

Без этих переменных ИИ-помощник вернёт ошибку, но остальной функционал
продолжит работать.

## Как пользоваться

1. Откройте http://localhost:5173
2. Выберите раздел в левой панели
3. Заполните поля; обязательные отмечены жёлтой рамкой
4. Используйте справочник ФПСР в разделе I и в разделе VII
5. Для помощи нажмите одну из кнопок в панели «ИИ-помощник» справа
6. Нажмите «Скачать Word» — файл `methodology.docx` сохранится
